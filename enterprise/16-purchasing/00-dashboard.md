# Dashboard

![](https://cdn.realsgii2.dev/wise-software-docs/image_2.46219917.png)

The purchasing area dashboard is divided into three main sections.

On the left you will find a listing of all purchase order history. If a purchase order is still open there will be a a quick action button on that line that will open up the receiving view.


# Last Ordered

This will show the last 50 items purchased.

# Cost Changes
This will show the last item costs that have changed.

# Invoices
This will show the last 50 invoices created from purchase orders.
